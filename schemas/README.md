# 机器可读结构

JSON Schema Draft 2020-12，来源为当前 TypeScript 合同。这里是**规范化输出结构**：必填属性可能由游戏解析器补默认值。结构校验不包含全部数值范围、跨对象引用、规则版本、授权及业务条件，最终以客户端导入／源码解析器为准。没有网络 API 的 schema 不会因此变成网络 API。
