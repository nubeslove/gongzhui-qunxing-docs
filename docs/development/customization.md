# 自定义能改到什么程度

| 修改对象 | 现有方式 | 是否需重建程序 |
| --- | --- | --- |
| 玩家主题、字号、快捷键、减少动态效果 | 客户端个人设置 | 否；属于个人偏好 |
| 角色、能力说明、道具、任务、地图、演出、事件 | 世界编辑器、导入格式、本地备团接口 | 否；受合同与权限约束 |
| 头像、三种立绘、地图、音乐、视频、GLB | 世界附件／资源库 | 否；受格式、尺寸与字节限制 |
| AAF 天赋与共鸣资源定义 | AafCatalog 与工坊保存路径 | 数据可变；新的算法需代码 |
| LANCER 自定义武器与系统 | 已注册的 automation JSON | 支持的节点不用；新节点要重建 |
| DND/心海自定义规则能力 | StoryResource + 已接入执行器／明确裁定 | 说明可改，任意复杂机制不能仅靠文字自动化 |
| 宏 | 既有聊天、掷骰和受权限限制的脚本路径 | 不代表第三方插件机制 |
| 新战斗算法、系统 ID、侧栏页面、全局菜单 | 修改合同、引擎、会话和 UI | 是 |
| 新 HTTP 路由、对象存储、短期 TURN 票据 | 服务端与客户端协议修改 | 是，需配对发布 |

目前没有承诺兼容的外部插件 SDK、目录扫描加载第三方 JS、安装包旁随意覆盖前端文件，或将任意资源 URL 作为代码执行的机制。扩写文案与扩展计算是两个不同支持级别。

## 宏与自动化数据

宏的文档结构为 `WorldMacro`：`type: chat/roll/script`、`body` 和文档权限；参数是最多32项的简单 JSON 值，名称为英文标识，文本最多2,000字符。`{{args.name}}` 用于文本替换。快捷栏为五页，每页十格。

脚本宏权限与运行环境需按当前客户端入口核对，不应因为可以创建 `type:script` 就视为能执行任意 Node／文件系统／HTTP 命令。区域自动触发目前只绑定聊天或掷骰宏，且固定宏 revision；脚本宏不能套用到区域自动触发。详见 [宏字段](../../reference/packages/contracts/src/world-macro.md) 与 [命令说明](../api/commands-and-network.md)。

## 新执行器应补齐的路径

合同与输入解析 → 规则纯函数 → GM 结算 → 资源与行动费用 → 决策队列 → 日志／可见性 → 持久化／恢复 → UI 入口。对权限不足、过期修订、失效目标和取消操作保持原子性。不要只在动画播放后扣生命，也不要让玩家端提交自己算好的随机结果。

## 数据包的稳定边界

保留作者旧资源快照，新增版本使用新 revision；角色已支付天赋费用或装备快照不因目录更新而悄悄改变。导入前预览冲突，迁移时明确重映射哪些 ID。图片文本和视觉特效不能改变战斗身份、阵营、伤害类型或控制权。

若希望让社区开发第三方插件，应另设计权限声明、生命周期、隔离、版本协商和卸载迁移。此文仅确定边界，没有宣称该插件系统已经存在。
